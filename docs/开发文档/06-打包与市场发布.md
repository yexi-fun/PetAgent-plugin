# 打包与市场发布

## 1. 发布前清单

- manifest 的 ID、SemVer、`petAgent`、targets 和 entry 已确认；
- README 说明功能、配置、运行时依赖和可信代码风险；
- `permissions` 与实际行为一致，但不写成“宿主会强制限制”；
- Windows x64/ARM64 的入口文件分别准备；
- 契约测试覆盖 initialize、health、调用、停用和失败恢复；
- 包内没有绝对路径、`..`、反斜杠或符号链接；
- 不把 API key、用户数据或构建缓存打进 ZIP。

## 2. 生成归档

```powershell
Set-Location E:\projectdata\PetAgent-plugin
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\package-plugin.ps1 -PluginId com.example.echo
```

可选参数：`-Version 0.2.0` 覆盖模板版本；`-Release` 是兼容参数，当前脚本不生成签名。

脚本会建立 `artifacts\<id>\<version>\payload`，写入最终 `manifest.json`，计算 payload SHA-256，并生成 `<id>-<version>.zip`。ZIP 根目录必须直接包含 `manifest.json`。

当前脚本自动构建/复制 `mcp`、`frontend` 和 `native-dll`。sidecar/provider 的运行时由宿主支持，但此脚本尚未替它们构建二进制；请在发布前扩展脚本的分支或按同样目录手工准备 payload。

## 3. 生成市场索引

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\publish-market.ps1 -Tag market-v1 -SkipRelease
```

该命令读取 `artifacts` 下所有 ZIP，生成 `market/index.json`（插件、版本、下载 URL、ZIP SHA-256、channel）和 `market/security/revocations.json`（人工撤销记录，目前不会自动阻断客户端）。

检查后提交索引和源码：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\validate-market.ps1
git add market docs plugins scripts
git commit -m "release: publish plugin market metadata"
git push origin main
```

## 4. GitHub Release

先推送 `main`，再创建不可变 tag 和同仓库 Release 资产。非 `-SkipRelease` 模式会调用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\publish-market.ps1 -Tag market-v1
```

当前默认市场源是：

```text
https://raw.githubusercontent.com/yexi-fun/PetAgent-plugin/main/market/index.json
```

生产环境建议让索引中的 `downloadUrl` 指向同一仓库的 Release 资产。宿主会限制市场 URL 为 GitHub HTTPS 主机，并检查下载大小、索引仓库和包身份。

## 5. 更新、下架和回滚

- **更新**：发布新 SemVer，保留旧 ZIP 和上一版本信息；启用中的插件会先停用，升级后重新 health 检查，失败则恢复旧版本。
- **下架**：从 `market/index.json` 移除版本，并在 `market/security/revocations.json` 记录原因；通知用户停用/卸载。撤销文件不是密码学撤销列表。
- **回滚**：宿主保留 `previous_version`，回滚后默认 disabled，确认版本后再启用。

## 6. 市场文案要求

README 和索引描述应明确：插件运行于可信代码模型，可能访问宿主用户权限范围内的资源；`permissions` 是能力标签，不是沙箱授权。不要声称“已签名”“无法访问文件”或“宿主自动隔离”，除非未来实现确实改变并同步更新本组文档。
